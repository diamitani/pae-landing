What is PAE?

The Autonomous Prospecting Operating System

PAE is a master framework that unifies 5-Pillar outbound architecture, n8n workflow compilation, and execution diagnostics. Build prospecting engines that scale from 10 to 10,000 prospects per day with deterministic data flows, AI synthesis, and zero CRM pollution.

🛡️

CRM-First Architecture

Every prospect passes through a CRM Dedupe Shield before contact. Zero deal collision risk—the system automatically checks for active opportunities, existing client tags, and domain ownership before any outreach.

  • Queries HubSpot, Salesforce, Attio, or Pipedrive
  • Checks active deal stages and client status
  • Halts on domain match or existing relationship
🤖

Deterministic + Agentic

Use deterministic nodes for triggers, filters, deduplication, and enrollment. Reserve LLMs strictly for unstructured research and 3-sentence Problem-Agitate-Solve copywriting—no hallucinations in your data pipeline.

  • Deterministic: triggers, filters, CRM queries
  • AI: company research & personalized copy only
  • Claude 3.5 Sonnet, GPT-4o, DeepSeek support
✅

Human Approval Gates

High-impact actions default to approval mode. Send rich Slack cards with 1-click confirmation webhooks. Approve or reject batches before enrollment—no surprises, full control.

  • Slack Block Kit approval cards
  • Batch review with prospect summaries
  • Auto-enroll or manual review per campaign
📊

Full Execution Observability

Built-in error handling and structured run data. The framework includes diagnostic tools to analyze node-level failures, extract error messages, and synthesize remediation plans automatically.

  • Node-level error extraction from runData
  • Root cause analysis with HTTP status codes
  • Export diagnostics as Markdown or XLSX
Architecture

The 5-Pillar Framework

Every prospect automation engine is built on five core pillars. This architecture ensures zero CRM pollution, deterministic data flows, and AI synthesis only where it adds value.

📥

1. Trigger Ingest

Flexible prospect ingestion from multiple sources. Start workflows from webhooks, scheduled CRM syncs, or CSV uploads. Supports real-time intent signals and batch processing.

  • Webhook triggers for real-time streams
  • Scheduled CRM syncs (daily, hourly)
  • CSV/spreadsheet batch uploads
  • Intent signal webhooks (RB2B, Clearbit)
🛡️

2. CRM Dedupe Shield

The mandatory safety layer. Query your CRM by domain and email before any contact. Automatically halt on active deals, client tags, or existing relationships.

  • Check active deal stages & pipelines
  • Verify client/customer tags
  • Domain-level deduplication
  • Prevent sales team overlap
🔍

3. Contact Reveal

Enrich prospects with accurate contact data. Use Clay, Apollo, ZoomInfo, or Amplemarket with boolean ICP filters for role-specific targeting.

  • Boolean ICP title matching
  • Email verification & validation
  • Company firmographic enrichment
  • Multi-provider waterfall logic
✍️

4. AI PAS Copywriting

Generate personalized 3-sentence emails using the Problem-Agitate-Solve framework. LLMs research the company and craft contextual, relevant copy.

  • 3-sentence PAS structure
  • Company-specific research synthesis
  • Claude 3.5 Sonnet or GPT-4o
  • Template variables for scale
📧

5. Sequencer Enrollment

Enroll verified, enriched prospects into email sequences. Supports Smartlead, Instantly, Lemlist, and HubSpot Sales with personalized copy injection.

  • Multi-platform sequence support
  • Dynamic variable injection
  • CRM status tracking
  • Unsubscribe & bounce handling
Production Pattern

The 9-Node Canonical Workflow

Every PAE implementation follows this proven 9-node graph. It's the battle-tested pattern for building scalable, observable, and safe prospecting engines.

01
Pillar 1

Trigger Ingest

Ingest raw prospect stream from webhooks, schedules, or CSV uploads.

n8n-nodes-base.webhook | scheduleTrigger

Implementation Details

Supports three ingestion patterns: (1) Webhook with binary data for CSV, (2) Scheduled CRM sync pulling uncontacted leads, (3) Real-time intent signals from visitor ID tools.

02
Data Layer

Data Normalizer

Clean domains, trim whitespace, normalize job titles, standardize schema.

n8n-nodes-base.code (JavaScript/Python)

Implementation Details

Code node that sanitizes input data: extracts root domains, removes special characters, normalizes job titles to consistent format, and ensures all required fields are present before CRM check.

03
Pillar 2

CRM Dedupe Gate

Query CRM by domain/email. Halt on active deals or client tags.

HubSpot | Salesforce | Attio | Pipedrive

Implementation Details

Queries your CRM system by domain and email. Checks for: (1) Active deals in pipeline, (2) Client/customer tags, (3) Existing contact records. Drops prospects with matches to prevent overlap.

04
Pillar 3

Data Enrichment

Contact reveal with ICP title filters via Clay, Apollo, or ZoomInfo.

Clay | Apollo | ZoomInfo | Amplemarket

Implementation Details

HTTP Request to enrichment provider with boolean ICP filters (e.g., ["VP of Sales", "Head of RevOps"]). Returns verified emails, phone numbers, and firmographic data. Supports waterfall logic across providers.

05
Pillar 4

AI PAS Reasoner

LLM generates 3-sentence Problem-Agitate-Solve personalized copy.

Claude 3.5 Sonnet | GPT-4o | DeepSeek

Implementation Details

AI agent researches the company/role and generates: (1) Problem: specific observation, (2) Agitate: quantified friction/loss, (3) Solve: low-friction intro with clear CTA. Uses structured prompts for consistency.

06
Safety Gate

Approval Switch

IF/Switch routing: auto-approve or send to Slack for human review.

n8n-nodes-base.if | switch

Implementation Details

Checks workflow config for auto_approve flag. If false, routes to Slack approval node. If true, proceeds directly to CRM upsert and enrollment. Enables campaign-level safety control.

07
CRM Layer

CRM Upsert

Create or update contact with OUTREACH_ACTIVE status and AI notes.

HubSpot | Salesforce | Attio | Pipedrive

Implementation Details

Upserts contact record with: status = OUTREACH_ACTIVE, AI research notes in custom field, enrichment data (title, phone, company), and campaign tracking properties. Sets lifecycle stage appropriately.

08
Pillar 5

Sequencer Enroll

Enroll in email sequence with personalized PAS copy and tracking.

Smartlead | Instantly | Lemlist | HubSpot

Implementation Details

Enrolls verified prospect into specified sequence campaign. Injects personalized variables (name, company, PAS body, custom icebreaker). Syncs enrollment status back to CRM for observability.

09
Approval Path

Slack Alert

Rich Block Kit card with prospect summary and 1-click approval webhook.

n8n-nodes-base.slack

Implementation Details

Sends Slack message to SDR channel with: prospect details, AI research summary, PAS email preview, and action buttons (Approve/Reject). Approval triggers webhook that resumes workflow at Node 07.

Key Features

Built for Production Scale

PAE isn't a prototype—it's the framework for building real revenue engines. These features ensure your workflows are safe, observable, and scalable from day one.

🔐

Zero Hardcoded Secrets

All API keys, credentials, and sensitive data live in environment variables or n8n credential stores. Workflows use expression syntax like ={{ $env.API_KEY }} for secure, portable deployments.

  • Environment variable injection
  • n8n credential store integration
  • No secrets in workflow JSON
  • .env.template for easy setup
🧩

Sub-Workflow Modularization

Isolate repeated business logic into dedicated sub-workflows. Domain deduplication, company enrichment, and web scraping become reusable modules called via executeWorkflow nodes.

  • DRY workflow architecture
  • Shared enrichment modules
  • Version-controlled sub-workflows
  • Simplified debugging & updates
🔌

MCP (Model Context Protocol) Integration

Connect AI agents to your n8n instance via MCP. Expose approved workflows as tools that Claude, Cursor, or custom agents can discover and execute with proper permissions.

  • Instance-level MCP control plane
  • Expose workflows as callable tools
  • AI agent workflow orchestration
  • MCP client nodes for external servers
🩺

Execution Diagnostics & Self-Healing

Built-in error analysis tools. Extract node-level failures from runData, identify root causes (401 Unauthorized, 429 Rate Limit, 500 errors), and get step-by-step remediation plans.

  • Node-level error extraction
  • HTTP status code analysis
  • Automated remediation synthesis
  • Export diagnostics as Markdown/XLSX

Get Started

Deploy Your First PAE Workflow

Import the 9-node template, configure your credentials, and start building CRM-shielded prospecting engines in minutes.

1

Clone the Repository

Clone the PAE repository to access the 9-node template, build docs, and reference implementations.

2

Configure Credentials

Set up your CRM, data provider, AI model, and sequencer credentials in n8n or via environment variables.

3

Import & Customize

Import the .n8n.json template into your instance, customize ICP filters and PAS prompts, and activate.

# Clone the repository
git clone https://github.com/yourusername/prospect-automation-engine.git
cd prospect-automation-engine

# Copy environment template
cp .env.template .env

# Configure your credentials in .env
# HUBSPOT_API_KEY=your_key_here
# CLAY_API_KEY=your_key_here
# ANTHROPIC_API_KEY=your_key_here
# SMARTLEAD_API_KEY=your_key_here

# Import the 9-node template in n8n
# Settings → Import Workflow → Select pae-9-node-template.json
